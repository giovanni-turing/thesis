Thesis figures — redesign review

18 figures, each rendered fresh in plotly from the same underlying data (no GPU; CPU-reproduced the few GPU-only derivations). Left = current thesis figure, right = proposed replacement. Nothing in figuras/ was touched. PDFs + interactive HTML are alongside each PNG in figuras_new/.

Context tokens vs image count eda_a_context_vs_numimages

Added a two-level uncertainty band (p10–p90 + p25–p75) and an explicit ≈64-tokens/image reference line so the slope claim is visible on-chart; hover exposes the sample count n behind each image-count bin.

Seven-day arrival signals eda_c_seven_day_signals

Shared-x zoomable panels with midnight day-boundary gridlines and a filled vision area so the diurnal rhythm and burst envelope are legible; p99 line kept.

Demand-signal autocorrelation eda_d_acf

Marked the actual half-life crossings (9 vs 69 min) with droplines + labels — the scientific payload — instead of only the generic 0.5 line.

Images vs request rate eda_d_img_vs_req_scatter

Replaced a 10k-point overplotted scatter with a 2-D density heatmap: the mass concentration near the origin and the weak trend are now both readable; R² called out.

Faithful 3-panel port with interactive log axes and hover; cleaner Poisson-vs-empirical marker contrast.
