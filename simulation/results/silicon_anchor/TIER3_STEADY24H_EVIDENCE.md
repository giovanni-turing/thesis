- **Table-provenance disclosure (material):** the D63-verified burst3 pair
  reproduces digit-exact ONLY from the tier-5 rerun table
  (`reps/engine__vllm_serving/vllm_eager_dense_rerun.json`, sha
  9174d523…); the canonical phase-E manuscript-replication artifact yields
  745.758 / 747.169 for the same cell (Δ1.24 ms, same PASS). Both the
  original D63 computation and the reviewer's independent reproduction
  therefore used the rerun table. `steady24h_vllm_retimes.json` banks BOTH
  tables side by side (canonical steady24h values: fc/re 738.751/742.587,
  static 434.516/435.497 — same verdicts), sets its headline triple to the
  rerun table for like-for-like consistency with the verified burst3 pair,
  and records both table hashes. Any manuscript propagation must state
  which table it uses.
- **Order-statistic coincidence (verified genuine):** fc and re retime to
  an IDENTICAL vLLM p99 to full float precision despite different
  dispatches (39,906 vs 39,899 batches) and 1,686 differing per-request
  delays — the p99 index lands on equal values; neighbours, p99.9, and max
  all differ. Recorded in the artifact.
- **Beyond-p99 honesty caveat:** the bound is a p99 bound. Retimed maxima
  exceed 1000 ms for fc (≈2,199–2,207 ms) and re (≈3,893–3,904 ms) and
  marginally for static (≈1,163–1,165 ms), mirroring the already-banked
  simulator tails (2,088.6 / 3,701.5 / 1,128.6 ms) — a property of the
  banked schedules, not introduced by retiming.
- **Coverage:** steady24h dispatch N-distribution p50=1, p90=36, p99=64,
  max=64 in all three cells; every dispatched N is an exact key of the
  dense N=1–64 vLLM tables (no interpolation exercised). The calm day
