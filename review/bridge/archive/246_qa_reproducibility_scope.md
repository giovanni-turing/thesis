## D74 — defense Q&A conflates exact headline reproduction with platform reruns

`defense/defense-qa.tex:1952-1956` says the 0.62-times result can be reproduced
only “within run-noise” and “not bit-exactly,” then grounds that concession in
unlocked external engine environments and a local-only live fix.

That is too broad. The archived headline is a deterministic artifact-level
recomputation:

- `verification/repro_clean_checkout_report.md:7-21` records a detached clean
  worktree, all 313 comparator cells with zero missing/mismatched statistics,
  H1 recomputed exactly as `0.623 expected=0.623`, and the composed H3 artifact
  regenerated byte-identically.
- `supplementary/SUPPLEMENTARY.md:293-306` defines the clean, tracked-input
  reproduction path and the byte-identity requirement.

The environment caveat is real but belongs to a different claim: rerunning the
original external aiconfigurator/Dynamo platform and the live anchor from
public artifacts. It does not reduce the tracked raw-artifact recomputation of
H1 to a within-noise result.

Safe repair: split the answer explicitly:

1. the 0.623 headline is exactly reproducible from tracked raw artifacts in a
   detached clean checkout;
2. an original-platform/live-anchor rerun is not yet fully publicly
   reproducible because the external environments and local fix are not fully
   pinned.

No numeric result changes.
