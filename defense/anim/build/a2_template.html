Scope. Both controllers use the identical worker law (C = ⌈demand/ρ⌉, ρ = 15 img/s, 3-min scale-down hysteresis) and cold-start lead L on the same open-loop trace replay. The forecast lane reads the archived Chronos-2 or Toto-2 p90 path (header toggle; core-window Toto endpoints match the ledgered Toto factorial rows, e-window Toto cells are new runs) actuated on forecast issue time (warm-pool readiness); the reactive lane reads the trailing observed 15-s image rate. Every curve is converter output (the exact ledgered pipeline re-run with per-second series, under the manuscript's load-bearing snapshot encoder graph); endpoint p99s reproduce the ledgered values to the third decimal, and the running mean/p99 tickers are recovered from the per-request seam timestamps (cross-checked against each run's stats). L = 165 s reactive cells are new runs under the same law. The first five episodes are the thesis's evaluation windows (burst2/6 excluded: they fall in the forecast-context days, so no archived forecast exists). The e-episodes are additional in-coverage bursts from the trace's full 18-episode set (thesis Ch. 3 definition, re-derived exactly; ranks 10/11/13/17 by peak) — new cells, not in the thesis, run under the identical ledgered law. On e10/e11/e17 the reactive controller fails at every lead while the forecast holds the 588 ms floor — three more burst3-class cases. e13 is the honest boundary: an isolated moderate burst (263 img/s, 7-min onset) rising out of the quietest stretch, where the p90 band — calibrated to ~90% coverage, riding a calm history — never lifts, so both policies fail (and inside the ledgered week-aggregate replays the same minutes read p90 4.55 s / reactive 2.89 s / p50 16.1 s / static C2 7.9 s — only static C8 passes at 882 ms; ρ=10 does not repair it, since no rating multiplies a missed forecast). Isolated-window replays of e-episodes open cold (no standing capacity from surrounding activity), matching the thesis's own per-window factorial protocol.

Cost accounting. Cold start is fully modeled in timing — ordered capacity becomes usable only after the lead L. Two billings are shown. The headline number bills from readiness (warm-up unbilled): the thesis's ledgered convention, applied identically to both lanes. The "incl. cold-start warm-up" line (also used by the footer totals) bills from order: each upward worker-increment additionally pays its L-second warm-up. That is exact for the reactive lane (every re-up is a fresh order) and an upper bound for the forecast lane (warm-pool re-ups charged as if re-ordered), so it is conservative against the forecast. Reactive churns far more (e.g.\ burst1 at L=45: 649 ordered worker-increments vs 127), so order-billing widens the forecast's advantage.
